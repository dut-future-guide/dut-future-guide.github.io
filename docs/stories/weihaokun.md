# 卫昊坤：人生如逆旅，我亦是行人
这篇简介写于2026.9.3，在基本确定了保研去向后，简单写下这篇对于我大学三年生活的回顾，供各位阅览。若留下探索，后人总结；若留下经验，后人咀嚼；若留下教训，后人借鉴；若留下失误，后人避免。希望我的经历能够对你有所帮助( ´ ▽ ` )ﾉ。

## 入学与大一生活
我的大学生活，要从入学时的心路历程来讲起。由于我是从河南高考来到的大工，河南高考给我带来的心理阴影过大，所以我入学时的想法就是期望自己在未来大学生活不要活的那么黑暗，能够放轻松去体会我的生活，快乐的活着。大一也确实如此，除了完成必要的学业（这里有个小tips,对于大一刚开学的数学课高数和线代，大工曾经有个讲课很好的教师叫闫浩，他在学习通中上传了他之前讲课的录像，讲课讲的很好，我大一下的高数就是听他的课学的，你可以在学习通中搜一搜他的名字，不知道这些课还在不在，希望对你有用），简单参加了学院的部门，在宣传部里面当了一个干事，然后参加了学院的一些活动，这个大一就在快乐的玩耍与生活中过去了。是的我的大一生活就在这种为了弥补的懈怠与不知何去何从的迷茫中过去了，而我后面的大学生活中其实也是一直在迷茫与不知所措中兜兜转转。

## 选择与分流
接着就来到了要分流的时候，迷茫，迷茫，还是迷茫，面对学院的5个方向，我那时候其实是感觉我选哪个都行，因为我大一的成绩也不算差rank10%左右，但因为高中卷的太累了我不太想在人工智能卷，于是分流我选择的是未来的化学方向，保证我自己无论未来怎么样，起码一定有一个保研名额保底。但还是没逃掉，哭哭，没想到想在化工专业拿一个比较不错的rank还是不容易的，还是得卷，甚至由于人数较少38人，导致你排名差一名，你的rank比例就会掉很多。主要是我们这届选化工的人太卷了，但有些专业不是这样的，所以对于各位而言，选分流方向还是一个比较重要与艺术的操作，如果你选的好，你是有可能比较轻松的拿到一个好的rank，然后腾出一些学习时间来去做科研或者竞赛这种其他的事情，可能会轻松一些，不用为成绩而焦虑。（我最后的rank是4/38供大家借鉴）

然后就到了大二，大二对于我的我只能说开始为了我的未来做了些工作（主要是不想过的那么浑浑噩噩）于是我竞选上了未来的媒体运营中心部长（这个得吐槽一下学院的部门活多给的好处有点少，但我也正是在这个部门任上认识了很多与在这里这个些写文章的大佬，认识了很多新朋友，也是收获颇多）参加了一些数模竞赛，还有化工专业的相关竞赛（这个也得吐槽一下，化工的竞赛跨度长，产出比不够，不建议参加），还有就是根据参加的这个化工的竞赛和同学老师水了一篇论文。就在这样跟着大佬的步伐学习试错，与部门工作中大二就过去了

## 大三：ai for chemstry
大三是充满焦虑与迷茫的一年，看着身边的大佬同学通过前两年的奋斗，都有了很好的科研产出，我陷入了对于未来保研的交流之中，因为我没有什么能够拿的出手的科研项目。于是在焦虑了好一阵之后，我觉得不太行，正好那时候化工专业有个化学信息学的课是刘奇磊老师教的，之前在导师双选的时候也了解过，于是我主动去找了老师说我想在大三期间做出一篇能够拿的出手的论文，就这样我开始稀里糊涂的走上了ai for chemstry的科研方向。我所做的科研内容是机器学习势函数这个领域，具体来说是使用ai相关的大模型与算法解决计算化学方面的问题，传统DFT的计算方式耗时长，效率低，无法支持大规模催化剂配体过渡态计算筛选的这个问题。具体在核心方面主要涉及的是图神经网络,等变图神经网络，等变transformer这些能够处理3维任务的算法方向，来进行回归预测分子间势能这方面的内容。在老师和师兄的鼎立帮助下，课题进展的还是很顺利的，取得了不错的成果。（这里给大家推荐一些我的导师刘奇磊老师，老师很nice，很年轻有实力，还好相处，相处起来是那种平辈的松弛感，有什么困难都会帮助你，如果大家想做ai for chemstry这个方向在大工刘老师十分推荐）。也是多亏了这方面的经历，在我保研的这段时间这个项目经历给了我决定性的bg。（这里我要提一下对于学院ai4s这个方向，大家仁者见仁智者见智，既有ai4s偏向s去做实验（这里指化学那种实验，我不太喜欢）的方向与同学，也有像我这种其实着重与ai算法的，我保研的方向也是着重与ai算法，所以对于ai4s这个新型领域，其实他的定义与边界很模糊，你很难根据你的专业去定义，仍等待后来者去耕耘，是个大有可为的领域）

## 慢慢走，你走的每一步都算数
回顾我的大学生活，其实可以看见我并没有像其他同学那样有一个很明确的方向与目标，甚至很多时候连努力的动力都没有，经常是三天打鱼两天筛网，走一步看一步这样子，很多时候我都是迷茫的，很多时候都是被身边的大佬也好ddl也好推着往前走，在努力与摆烂中左右摇摆，你很难保证你的每个选择都是正确的，我的大学的路也是在一点点试错中摸索。正如现在一样，虽然我现在有了一个我认为值得满意与庆幸的offer，但这个选择是否正确，将如何影响我未来的生活我也是十分迷茫，所以各位请向前看吧，希望你着眼于眼前的点点滴滴，按照你期望的方向，活出你理想中的生活，相信你会有更加浪漫，更加热烈，更加充满青春与梦想的未来。
**慢慢走，你走的每一步都算数。**
