# 丛渝轩: 不要怕痛苦，勇敢开智

莫言说，早熟的人大多晚熟，我想我便是那样一个人。

成长或者说开智，往往伴随着阵痛，并且这种阵痛是无可避免的。一个人在社会定义下的成年是18岁，但是实际上我们的心理的成年或许会延后一段时间，甚至是相当长的一段时间，再或者说，心理上的成年不止一次。我认为在迫切的想要获得世俗上的成功(保研到你高中的梦校，本科期间就发表顶级会议的论文，在大学期间来一场众人艳羡的风花雪月)之前，我们需要先问自己真正需要什么，这也正是一次次开智或者一次次思考所能尝试去迭代求解的一个问题。

## 我目前的开智史

我想，截至目前，我总共或许开智了三次，下面一一列举。

### 学海扬帆

小学升初中，突然发现自己的成绩很好，并且老师和家长对我有另外的期待，故觉得学习是一个不错的策略，可以让我获得一些物质和精神上的奖励。这种状态一直持续到高考结束。我想这也是很多读者所经历过的。

### What is love (baby you hurt me~)

18年的压抑，见过了高中那些同学们的校园地下恋情。我无力啊，我只能疯狂的订正我的错题本啊，看见女生就会心跳加速，莫名的脸红。我下定决心，等高考结束后我一定……那时候对于大学的期待无非是手机自由、恋爱自由、时间自由。

但是love这件事，很复杂，难以用语言描述。懂的同学建议在大学复习一下，不懂的同学，可以尝试去预习一下。

总之这是一门实践性的经验性的事情，每个人或许都会从中有不同的领悟。比如说我领悟了哪些道理呢？第一，爱情不是你努力了就可以得到的，它是一个双向奔赴的过程。第二，爱别人需要先爱自己，自己永远是你本人在这个过程中的主体。第三，世间好物不长久，彩云易散琉璃碎。其余的还有一部分，但是这里地方太小了，我写不下。其实这已是好几段故事总结出来的结论了，道理谁都懂，书上都写着，但是纸上得来终觉浅，还是得自己去伤几次心，流几次泪才能体悟。

### 不再是一个学生

大一做了学生工作、文体活动、社会实践、科研竞赛，丰富充实，好不快活！到了大二下学期，意识到自己的成绩还不错，或许能够保研到外校，所以尝试去做一些科研工作，在网络上联系到了上海交大的一个博士生，于是跟着干了起来，我这个人主打一个行动力拉满，认准的事情不拖延，干了再说。

大三下学期，在不耽误课程的情况下，我去了线下进行实习。

孤身一人，和这座城市没有一丝一缕的关联。出租屋，公司，共享单车，深夜，失眠，一个人。在学校，我有朋友，有兄弟陪我排忧解难，但是在上海，这里的孤独与寂寞仿佛在炎炎夏日之中格外的冰冷刺骨。我尝试用酒精和尼古丁来麻醉自己的感知，但是那并不好，为什么不好，不必多说了。所以，学会自处，也是对于像我这样的群居动物来说必要的一课。我是如何自处的呢，我总结为一句话————做好自己的事，让自己开心。刚开始，我会每天留在实验室，最后一个走。但是后来，我会趁着实验在跑的时候去健个身，或者早点下班去周边开一个美食盲盒，或者去旁边的网鱼电竞来几把激情四射的瓦洛兰特……

我在实习的时候就隐约意识到，自己也许马上就不再是一个学生了。学生时代，你会上很多的课，然后去考试。但是如果读研究生，我觉得那更像是一份工作，你有你的工作内容，有你的老板，有你成果产出的ddl，会自己一个人遇到很多外界的压力，这时候如何取悦自己就显得尤为重要了。

ok，以上就是我目前的全部开智史了，其实人的成长实际上应该是一个日积月累的过程，我这里只是节选了变化率最大的三个时间节点，并讲述了一些故事，我也很期待我的下一次开智。

## 为什么需要开智

我前面叽里咕噜的讲了那么多，那么为什么需要开智呢？

我觉得道理很简单，人生在世，唯一所求便是自己能够快乐。开智或许不能帮我们一步到位地找到什么能够让我们快乐，但是貌似可以帮我们寻找什么会让我们不快乐。我想这也是很有意义的。时至今日，我依然十分感谢过去我走过的那些弯路以及路上那些人对我曾说过的话。某种程度上来说，错误比正确更具有学习价值。并且我记忆力其实不是很好，过去的那些痛苦貌似已经记不得了，留下的很多都是美好的回忆。人类的大脑或许也有这样子的功能吧，十分感谢啊。

所以，读者们，真心希望你们能够在大学这最青春的四年，遵循你的内心，不断地去探索那些你好奇的、想要尝试但未曾做过的事情。我至今未曾后悔过之前做过的那些"勇敢的尝试"，在探索中感悟，在感悟中开智，在开智之后慢慢去认清"自己"。

## 一些小 tips

### 如果你是一个卷王

- 向你上一届最卷的那个学长取经，如何在课程中获得高绩点，如何混点比赛，如何早早布局科研，让 Codex、Claude Code 大人带你发顶会 paper，如何最大化利用规则。
- 学会对所有人祛魅，任何人都是一个生物上的人类。不要对某些职业，带有某些标签的人产生滤镜。与其崇拜，不如深究他如何成为这样的人，然后学习，然后超越。
- 要有强者的心态，不到最后一刻，永远不要放弃。不要去在意别人的眼光。
- 不要嫌麻烦或者不好意思。
- 任何时候都要去算一下如何把期望的利益最大化这笔账

### 如果你还不知道自己想要做什么

- 大胆去探索吧，多尝试一下。人生如此之长。
- 尽量先保证自己的绩点排名，因为这是很多事情的基础。
