# 大学到底应该怎么过？

这个问题我大一的时候其实想过很多次。那时候总觉得应该存在一种“正确答案”：成绩要好一点，四六级早点过，参加几个比赛，做点科研，最好再有一些自己的兴趣爱好。如果这些事情都能兼顾，好像才算没有浪费大学。

但真正过完三年之后，我反而越来越觉得，大学可能根本不存在一个所有人都适用的标准答案。

这三年里，我认真卷过成绩，减过肥，健过身，背过单词，打过很多游戏，也折腾过科研，参加过比赛，谈了恋爱，出去旅游。很多事情做得不算特别厉害，也有不少选择现在回头看会觉得可惜，但整体来说，我还是挺满意这三年的。

因为相比于拿到了什么，我觉得自己更大的变化是：**我慢慢知道了自己喜欢什么、不喜欢什么，也开始知道自己愿意把时间花在哪里。**

大学和高中很不一样的一点，就是你突然拥有了非常多的选择。你可以把时间都用来卷绩点，也可以去搞科研、比赛、奖学金；可以学技能、找实习，也可以健身、旅游、打球、谈恋爱。

这些事情本身没有哪个更高级。

问题只是你一天永远只有24小时。当你花两个小时健身，就少了两个小时学习；周末出去玩了，可能就少做了一组实验；花时间谈恋爱，也就很难同时天天泡图书馆。

以前我总觉得，这些事情应该存在一个“最优解”。现在我越来越觉得其实没有。

**很多时候，你只能不断做选择，然后接受那些因为选择而没有得到的东西。**

只要你不是漫无目的地消耗时间，而是真的知道自己为什么这么选，那这条路就有它自己的意义。

# 大一：一天安排得越满，我反而越累

刚上大学的时候，我的思维其实和高中没有什么本质区别。我觉得大学无非就是一个自由一点的高中，所以还是很认真上课，也经常去图书馆。那时候大概两三天就会去自习一次，同时还在准备四六级，每天用“不背单词”背单词。

**这个 App 我现在依然觉得挺好用。**

如果高中英语底子还不错，我也确实建议大家：

**四六级能早点考就早点考。**

因为高中英语是真的会越忘越多，尤其是词汇和语感，大一的时候往往还是最好的状态。

除了学习，我当时还比较胖，所以决定减肥。于是每天又给自己安排了健身，力量训练、有氧基本都做。再加上我还喜欢打 CS，所以现在回头看，我大一上学期的一天其实安排得非常满：上课、写作业、背单词、健身、复习，再挤一点时间打游戏。

从结果来看，这段时间其实挺不错。六级过了，体重减了接近30斤，成绩也排到了前15%左右。

放在别人眼里，可能会觉得这个人大学生活挺自律。

但只有我自己知道，那段时间其实过得非常累。

我本身睡眠比较浅，室友又会打呼噜，所以晚上经常睡不好。更要命的是，我那时候减脂方法还有问题，碳水吃得非常少，每天又保持比较大的训练量。于是白天累，晚上又睡不好。

因为白天时间已经被排得太满，我还会觉得晚上睡觉的每一分钟都必须保证“高质量”。结果越这么想越睡不着，越睡不着第二天状态越差，然后第二天又继续上课、背单词、健身、写作业。

最后就形成了一个挺奇怪的状态：

**我每天都在做一些看起来非常积极的事情，但自己一点都不开心。**

这个状态一直持续到寒假。

回家以后，我才慢慢开始想，为什么明明很多事情都有结果，我却还是过得这么累。

后来我发现，也许不是这些事情本身有问题，而是我把一种大家普遍认为“优秀”的大学生活直接套在了自己身上。

我当然喜欢进步，但我也喜欢吃东西，喜欢出去玩，喜欢看看海，喜欢桌游、剧本杀，也喜欢偶尔什么都不干。

我可能本身就不是那种每天从早卷到晚还会觉得非常快乐的人。

想明白这件事之后，大一下学期我反而轻松了很多。六级不用准备了，健身也从单纯减脂慢慢转成了力量训练。体重降下来以后，看着自己的卧推重量、肌肉量一点点增加，健身也从一个必须完成的“任务”，慢慢变成了我真正喜欢的一件事情。

后来我重新开始打篮球，还和朋友一起成立了 FBC。

**有兴趣的学弟学妹也欢迎来一起玩。**

这一学期，我也开始注意穿衣、护肤这些以前不会太在意的东西。说实话，我以前也觉得男生搞这些挺麻烦，但后来发现还是有必要。

不是非得把自己弄成什么精致男孩，而是人收拾得干净一点、穿得合适一点，自己照镜子的时候心情确实会好很多。

穿搭这种东西我觉得也不用觉得不好意思，可以看看网上别人怎么搭，再根据自己的身材买回来试试。买错了也很正常，审美本来就是一点点试出来的。

护肤也是一样，不用十几个瓶瓶罐罐，基础清洁、保湿、防晒做好就已经够用了。尤其是平常经常运动的人，**防晒还是挺重要的，毕竟脸是要跟自己一辈子的。**

大一下学期，我的成绩没有第一学期那么好，但我反而更喜欢那一学期的状态。

因为也是从那个时候开始，我第一次意识到：

**大学不一定非得每天都把自己逼得特别紧。**

# 大二：开始知道自己喜欢什么，也开始主动去尝试

大一下分专业的时候，我选了智能建造。

原因其实挺现实，我当时觉得自己可能不是特别适合那种非常卷的赛道，所以想选一个相对轻松一点的专业，先把保研资格拿到，之后再想办法往自己真正喜欢的方向走。

我当时的思路差不多就是：

**先保证自己有继续读研的机会，再考虑未来具体去哪。**

听起来其实挺合理，但后来才发现，跨方向并没有当时想象得那么容易。

智能建造毕竟和土木还是有很强的联系，而这些年大家对传统土木行业的评价也都懂。我甚至听过一个挺夸张的说法：

“土木下一次黄金期可能要等下一次世界大战。”

虽然更多是在开玩笑，但这些声音确实会让人怀疑自己的选择。

我当时倒也没有特别担心，因为一直觉得以后还可以往别的方向转。后来真正开始接触科研之后才发现，跨专业当然可以，但不是你想去哪就去哪。老师会看你的本科背景，看你以前做过什么，也会考虑你和课题方向到底匹不匹配。

所以如果现在让我评价当初这个选择，我不会说它是一个错误。毕竟最后我确实比较顺利地拿到了保研资格，也给自己留下了比较多可以自由安排的时间。

但如果重新来一次，我可能会更早去了解不同专业未来到底能够走哪些方向，而不是只考虑“好不好保研”这一件事。

这一年我也开始接触一些交叉方向的项目。

跟着老师真正做东西之后，我第一次很明显地发现：

**学校里面很多事情，真的不会有人一步一步教你。**

老师给你一个问题，然后接下来怎么做，很多时候就得自己想办法。

环境不会配，代码看不懂，报错不知道什么意思，论文也看得很吃力。那时候最痛苦的一件事就是配环境，一个现在看来可能几十分钟能解决的问题，当时能折腾我好几天。

现在回头看会觉得这些问题其实没什么，但第一次遇到的时候，是真的完全不知道应该怎么办。

后来慢慢学会查资料、看 GitHub、问师兄，再配合 GPT 一点点把问题拆开。

所以我现在还是非常建议刚上大学的同学：

**早点接触 GPT 这类工具。**

但不要只把它当成抄答案的工具。

它真正好用的地方，是你可以一直追着问“为什么”：代码为什么这么写，这个环境为什么会报错，论文这里究竟想表达什么，一个陌生概念和另外一个概念到底是什么关系。

**很多东西不会并不可怕，真正麻烦的是不会，也不知道该怎么去找答案。**

GPT 可以让这个过程快很多。

当然它也会一本正经地胡说，所以最后还是得自己判断。

## 大二还有一件事：我开始主动认识更多人

因为大一大部分时间都在学习、健身，再加上平常认识的人基本都在学院里面，所以我的社交圈其实一直比较小。

后来时间稍微充裕一点，我也开始有了谈恋爱的想法，所以就开始主动想办法认识一些原本生活圈子之外的人。

这一部分我觉得还挺实用，所以可以分享几个自己真正尝试过的方法。

第一个是小红书。

很多男生可能平时基本不用，但如果你想扩大社交圈，其实这个平台挺好用。同校或者附近学校的人很多，也经常有人组局，比如密室、麻将、桌游、剧本杀之类。

自己判断一下，如果觉得靠谱就可以去。

哪怕不会玩也没关系，去一次就知道了。

也可以看看别人发的交友贴，或者自己发。很多人看到“交友贴”这几个字可能会觉得这是不是有点像相亲，其实完全不用想得那么复杂。

**对于大学生来说，这本来就是一种认识原本生活圈之外的人的方式。**

别人不回复也很正常，不要太在意。

**不要怕被拒绝，脸皮稍微厚一点，其实能认识很多人。**

第二个就是适当经营一下自己的社交媒体。

比如我以前会发一些健身的视频。如果你喜欢摄影、篮球、跑步、旅游、穿搭，其实都可以记录下来发出去。

不是说一定要当博主，而是别人想认识你，至少得先知道你平时在做什么、喜欢什么。

**社交媒体某种程度上就是你对外的一张名片。**

你长期坚持做一件事情，自然也更容易遇到有相同兴趣的人。

第三个就是学校里的各种活动和运动群。

我自己最推荐的是羽毛球。

因为确实比较容易上手，男女生都会玩，而且有双打和混双，社交属性挺强。

篮球如果想靠打球认识异性，难度确实比较大，羽毛球就自然很多。

技术不好的话，可以先体育课上学一学，再去群里约球。多打几次，很容易认识一些之前完全没有交集的人。

**我和我对象也是因为羽毛球混双认识的，所以这条路线至少我自己确实实践成功过。**

当然，认识人只是第一步。

最后能不能成为朋友，甚至发展成恋爱关系，还是得看两个人合不合适。

**你自己也得有一些属于自己的闪光点，所以我一直觉得，扩大社交圈和提升自己这两件事情最好一起做。**

# 大三：很多之前做过的尝试，慢慢有了结果

到了大三，我对自己的生活状态已经比前两年清楚了很多。

不是说这一年突然什么都顺利了，其实依然有很多不确定的事情，也会焦虑保研、论文、未来方向这些问题。

只是相比大一、大二，我已经没那么容易被别人怎么选择影响了，开始比较清楚哪些事情是自己真正想做的，哪些事情其实没必要跟着别人一起卷。

学业方面，因为专业里的很多课程和数学、物理相关，我学起来还算比较顺利。最后绩点大概3.2，也顺利拿到了保研资格。

从结果来看，我大一分专业时给自己设想的那条“选一个压力没那么大的专业，然后争取保研”的路线，最后算是比较平稳地走了下来。

当然，也不是说这个选择有多么完美。

它确实给我留出了不少时间，让我可以去做科研、比赛、健身、旅游和很多自己喜欢的事情，但同时也意味着我的绩点不会特别突出，有些选择也会受到限制。

**选择本来就是这样，得到一些东西，就会失去另外一些东西。**

科研方面，我通过之前带我做项目的老师认识了组里的一位师兄。后来我们根据老师提出的问题，一点点做研究，最后完成了一篇论文，目前还在投稿。

科研这件事情我其实没有特别多想讲的大道理。

最大的感受就是：

**很多东西别人可以告诉你，但你还是得自己完整经历一次。**

第一次读大量论文，第一次搭模型，第一次实验结果不对，第一次不知道怎么解释，第一次改论文、投稿，这些过程不真正走一遍，很难真正知道科研到底是什么。

而且很多当时觉得特别难的问题，过几个月再回头看，可能会觉得其实也就这样。

但你只有先经历那几个月，才会觉得它简单。

所以如果以后有学弟学妹想接触科研，我还是建议可以早点开始。

**不会很正常，先做起来比一直担心自己会不会更重要。**

这一年，我还参加了学院的一个挑战杯项目。最后比较幸运，拿到了国家级一等奖，我在团队里面排第四。

这个事情我也不想把自己包装得特别厉害。

我当时参加这个项目，本来就是希望让自己的简历再完整一点，而且也没打算主要靠这个项目去争很多加分，所以实际承担的工作并不是最多的。

最后能够拿到国家级一等奖，对我来说算是一件很幸运的事情，也确实让履历更完整了一些。

这件事情也让我慢慢意识到：

**大学里面不是所有事情都必须成为自己的主线。**

有的事情值得你花很多精力，有些事情起到补充作用就够了。

如果什么都想做到最前面，最后很可能什么都做得很累。

# 恋爱以后，我多了一个最好的搭子

到了大三，我和对象的感情也一直比较稳定。

如果一定让我形容恋爱给大学生活带来的变化，我觉得最明显的一点可能是：

**对象很多时候就是你最好的搭子。**

想吃什么东西，有人陪你一起去；想去海边看看，有人陪你；想逛街、打游戏、看电影，也都有人一起。

平常一些特别普通的小事，因为两个人一起做，好像也会变得有意思一点。

周末我们会去吃喜欢的东西，去海边逛逛，逛街、打游戏；假期时间长一点，就会一起去旅游，去不同的城市，吃不同地方的东西，看看当地的风景。

而且我觉得对象和普通朋友还是会有一点不一样。

朋友当然也可以一起玩，但很多事情你不一定每次都能找到时间完全一致的人。对象很多时候就是那个最稳定、最愿意陪你一起尝试各种事情的搭子。

我们可以一起去一个完全没去过的城市，也可以两个人什么计划都没有，在大连随便找一家店吃饭，然后去海边吹风。

这些事情放到简历上当然一点用都没有。

但我很喜欢。

甚至现在回想大学生活，很多真正让我印象深刻的事情，都不是考试考了多少分，也不是哪个项目做出了什么结果，而是和对象、朋友出去玩的那些很普通的片段。

以前我周末出去玩一天，可能还会想：

今天是不是有点浪费时间？

现在基本不会。

因为我越来越觉得：

**不是所有收获，都一定要转换成绩点、奖项或者论文。**

大学本身就是人生的一段经历，有些时间花在体验生活上，也没有什么问题。

而且大学可能是人生里面少数几个既有比较长的寒暑假，又暂时没有太多家庭和工作负担的阶段。

所以我还是挺建议大家，如果有机会的话，可以多出去看看。

不一定非得跑很远、花很多钱，有时候周末去周边一个城市待两天，也挺有意思。

至少对我来说：

**和喜欢的人一起去看看不同的地方，吃点没吃过的东西，本身就是我以前挺向往的一种大学生活。**

后来我发现，这些事情我也确实慢慢实现了。

# 健身这件事，我确实踩过不少坑

最后再单独聊聊健身。

因为我从大一开始减脂，到现在系统健身也差不多两年左右，不算什么特别专业的人，只能分享一点自己真正踩过的坑。

最大的坑其实就是吃。

我以前减脂的时候，总觉得少吃碳水就一定能瘦，所以一段时间把碳水压得特别低。

现在回头看，其实完全没必要这么极端。

**正常减脂一样可以吃碳水，重要的是整体热量和饮食结构，而不是把碳水当成洪水猛兽。**

蛋白质也是一样，并不是吃得越多越好，根据自己的体重、训练量和目标合理摄入就可以。

我挺推荐大家养成一个习惯，就是：

**买东西的时候看看配料表和营养成分表。**

这个习惯坚持一段时间以后，你会慢慢知道常见食物大概有多少蛋白质、脂肪、碳水和热量，也会开始知道自己每天到底吃了些什么。

尤其是饮料、零食和甜品，很多糖和热量真的比想象中高。你觉得自己好像没吃多少，但实际上摄入已经不少了。

训练方面，我自己目前比较习惯胸、背、腿、肩四分化。胸和肩最好适当隔开一点，因为很多推类动作都会用到肩。平常练胸和肩我在学校比较多，练背和腿有时候会去外面的健身房。

动作学习方面，我自己比较喜欢看谭成义，很多基础动作和健身问题讲得都挺清楚。

但如果刚开始练，我觉得最重要的其实不是研究什么高级训练方法，而是：

**先把动作做对，再考虑重量。**

刚开始特别容易觉得重量越大越厉害，但实际上动作不对，不但训练效果可能不好，也很容易受伤。

像卧推、深蹲、硬拉这些动作，如果后面慢慢开始上重量，更应该重视保护和安全。

补剂方面我觉得也没必要想得太复杂。

肌酸属于研究比较充分、很多健身人群都会使用的运动补剂；蛋白粉本质上也只是一个方便补充蛋白质的食品。

如果正常吃饭就能满足需要，那就正常吃饭；如果饮食不方便，再通过蛋白粉补一点也可以。

**真正重要的其实还是训练、饮食、睡眠和坚持。**

尤其是睡眠。

不要像我大一一样，一边减脂，一边训练量很大，一边又睡不好。

现在回想起来，很多当时觉得必须咬牙坚持的东西，其实完全可以用更舒服、更科学的方式完成。

# 如果现在再问我，大学应该怎么过

写到最后，我依然给不出一个“大学就应该怎么过”的答案。

我只能说，我自己的前三年大概是这样。

大一的时候，我很努力地按照一种别人眼里比较“正确”的方式生活。好好学习、减肥、背单词、健身，把每天安排得满满当当。最后结果不错，但自己并不开心。

大二的时候，我开始尝试把生活范围扩大一点。接触科研，学新的东西，认识更多的人，打球，也开始谈恋爱。很多东西都没有想得特别长远，就是先试试看。

到了大三，我没有突然变成一个什么都想明白的人，也依然会纠结未来到底去哪里、研究生做什么、现在的选择到底对不对。

但相比刚上大学的时候，我已经越来越清楚自己大概想过什么样的生活。

我拿到了保研资格，做了论文，参加了比赛，健身也坚持了下来，谈了一段自己很珍惜的恋爱，也去了不少地方。

当然，我也放弃了很多可能。

如果我当时把更多时间用来卷绩点，也许成绩会更好；如果把更多时间投入科研，也许现在能多一些成果；如果少出去玩一点，也肯定能多做很多事情。

这些我都知道。

但现在让我重新选择，我未必真的会把它们全部改掉。

因为我越来越接受一件事情：

**你选择了一个东西，本来就意味着没有选择另一个。**

大多数普通人很难同时拥有最高的绩点、最多的论文、最丰富的社交、最好的身材、最自由的旅行、最稳定的恋爱和最充足的睡眠。

所以大学真正要做的，也许不是想办法什么都拿到，而是：

**慢慢搞清楚，自己到底更愿意把有限的时间花在哪里。**

如果喜欢科研，就多去实验室。

如果喜欢比赛，就去做项目。

如果喜欢运动，就去健身、打球。

如果想谈恋爱，也可以主动认识人。

如果一直想出去看看，那就找个时间出发。

而且你完全可以改主意。

大一觉得自己想要的东西，到大二可能就变了；大二做的决定，也不一定非要一直坚持到毕业。

**别人的大学生活只能作为参考，不能直接拿来当自己的标准答案。**

我现在回头看大学前三年，当然有遗憾，也做过不少现在看来挺蠢的事情。

但整体来说，我还是挺喜欢这三年的。

至少我慢慢知道了自己喜欢什么，也真的花了一些时间去过自己想过的生活。

**我觉得这样，就已经挺好了。**

希望我的建议能对你们有所帮助，也希望你们能够找到适合自己的生活方式，拥有属于自己美妙的大学生活。
