# 赵建斌：那些把我带到今天的选择

这篇文章，是我对大学前三年的一次回望。

每个人都有自己的道路，而我想把自己走过的这条略显特别、也并非一开始就清晰的路写下来。它未必适合所有人，但如果你的经历、性格或困惑与我有几分相似，希望这些文字能够给你带来一点启发。

写下这篇文章的时候，我对未来的保研去向仍在抉择，也还在等待最后的结果。现实和最初的预想之间，当然有过不少差别。但如果回到大一刚入学的时候，告诉那时的我，未来能够走到今天这个程度，我大概会觉得自己是在做梦。

所以回头来看，我觉得自己的大学生活其实是幸运的。我很幸运地遇到了许多机会，也很幸运地在机会出现时，愿意相信自己，并且努力把它们抓住。

最开始，我想对学弟学妹们说的是：身处当下时，你永远不会知道未来的自己会走到哪里。不必过早焦虑，也不必急着给自己下结论。珍惜当下，认真做好眼前的事情，也尽量抓住遇到的机会。等有一天回头再看，你或许也会惊讶于自己的成长。

接下来，我会重点讲讲自己的科研经历。希望这段并不平坦的过程，能够给你带来一点点启发，也许在你心里埋下一颗愿意了解科研、尝试科研的种子。

## 大一：积极试错，慢慢靠近热爱

对于刚刚进入大学的同学来说，我觉得最重要的事情，是勇于探索和接触。

团学、社团、乐团，还有各种比赛，我都参加和尝试过。刚入学时，我并没有想过自己最后会走上科研这条路，直到大二，我才真正开始接触科研。现在回头看，大一的这些经历也许并没有立刻带来什么结果，但它们让我逐渐认识了自己。很多时候，方向不是一开始就想清楚的，而是在一次次尝试之后，慢慢排除不喜欢的事情，也慢慢靠近真正愿意投入的方向。

当然，在勇于探索的同时，自驱力也非常重要。进入大学以后，很多同学的思维还停留在“跟着老师学好课本、完成作业、准备考试”上。但大学的学习不应该只局限于课堂、课本和教室。网上有大量可以主动获取的资源，课程、论文、开源项目和各种实践机会，都可能把你带到一个新的地方。很多真正实用的能力，大学四年里未必会有人手把手教给你。如何查找资料、阅读代码、解决问题、完成一个项目，这些都需要自己主动探索。如果始终只是等待别人把答案递到手里，迟早会在真正需要独立解决问题时感到吃力。

如果你确实对科研感兴趣，在 Python 有了一定基础之后，可以尝试主动联系本院的老师。你可以带着自己的兴趣、已经做过的尝试，或者一个还不成熟但真实的问题去交流。不要因为自己是大一新生，就觉得老师一定不会理你。即使老师当下没有合适的安排，也可能会给你推荐一些资料，或者告诉你可以从什么方向开始。老师通常不会主动逐一联系学生，很多机会需要你先敲开那扇门。有人带你入门，确实能够少走很多弯路。但更重要的是，你要在这个过程中逐渐形成自己的判断，而不是永远等待别人告诉你下一步该做什么。

此外，大一就可以开始学着使用 GPT 等工具。它们不能替代思考，也不能替你完成成长，但可以帮助你快速查资料、理解概念、排查错误、整理思路。真正开始使用之后，你会发现，许多重复性的工作和信息处理，都可以因此变得高效很多。

关键不在于有没有工具，而在于你是否知道该怎样提出问题，以及如何判断工具给出的答案是否可靠。

## 大二：遇到机遇并抓住，开始科研之路

对我来说，大二是大学生活的一个转折点。那一年，我遇到了大学里最重要的一位学长。当时学长正在寻找愿意做科研的学弟，我联系了他。一起竞争这个机会的还有几位同学，很幸运我没有在最开始就退缩，而是最终坚持了下来，而学长也最终选择了我。

但科研从来不是一条轻松的路。刚开始做科研时，我明显感到痛苦。到了前沿领域，书本上的知识往往很难直接拿来解决实际问题，很多东西都需要自己查资料、读论文、跑实验，一点一点补起来。学长和老师能够带给你的，首先是方向感：告诉你这个领域有哪些内容值得学习，应该从哪些论文读起，也带你去理解前人工作的思路、创新点和不足。但具体该怎样学习，怎样把看过的东西真正变成自己的理解和能力，最终还是要靠自己。

而这个过程，往往极其耗费时间，也很难立刻看到结果。从大二初开始跟着学长做项目，一直到大二快结束的时候，虽然中间也有一些阶段性的产出，但真正由我主导、能够代表自己的成果，其实还没有形成。实验失败、模型训练崩溃、方案被推翻，甚至自己的 idea 被别人抢先做出来，都是常有的事情。

这些经历并不轻松。很多时候，你会反复怀疑自己，怀疑自己的能力，也怀疑自己是不是根本不适合做科研。但一次次失败之后，你又只能重新把问题捡起来，继续查资料、改代码、跑实验。这个过程像是在不断捶打自己，让人慢慢学会面对不确定，也学会接受短时间内看不到结果的状态。

回顾整个大二，我最大的收获并不只是某一个具体结果，而是第一次接受了相对系统的科研训练。我开始接触算力的使用和维护、项目代码的管理、GitHub 的协作与上传，也逐渐学会了如何记录实验、分析问题和复盘过程。这些看起来琐碎的积累，后来都成为我继续做科研、并在大三很幸运收获成果的重要基础。

所以，对于想做科研的同学来说，耐得住性子是一件非常重要的事情。科研不太适合因为一时兴起、脑门一热，就觉得自己一定能够坚持下去；它也不适合那些急于在短时间内得到结果的人。更多时候，科研需要你慢慢来：把问题看懂，把基础补齐，把一次次失败记录下来，再逐渐形成自己的判断。你需要接受一段时间里没有明显成果，甚至不断怀疑自己的阶段。当然，耐住性子并不意味着盲目地坚持错误方向。真正重要的是，一边坚持，一边复盘；一边投入时间，一边确认自己是否在朝着正确的方向前进。

## 大三：先把种子埋下，才等得到收获

有了大二的积累，我对科研也逐渐有了一些更具体的认识。大二到大三的暑假期间，在同校老师的课题组里，我跟着一位师姐完成了一篇 CCF-B 类论文的投稿。随后，我开始了 CVPR 的赶稿之旅。可以说，整个大三上学期，我几乎都围绕着这篇文章展开。这也是在学长的帮助下，我第一次真正主导核心内容的工作。从最开始的问题发现、方法讨论，到模型设计与训练、实验验证，再到最后的论文撰写，我都深度参与其中。那段时间是我大学里最累、同时也是收获最多的一段经历。每天凌晨一点多之后睡觉，几乎成了常态；为了等待实验结果而通宵，也并不罕见。直到十一月截稿，整个人才终于有了一段可以停下来休息的时间。但也正是在那段日子里，我真正接近了研究生阶段的科研节奏。我第一次不再只是跟着别人完成任务，而是需要自己理解问题、参与判断，并且对最终结果负责。

在等待论文结果的同时，我也开始积极联系外校老师的课题组，寻找科研实习的机会，并逐渐考虑自己的保研去向。凭借这段论文经历，我顺利通过了北大以及南开大学相关老师的面试，进入课题组参与科研项目。当然，科研实习和最后能够去哪里读书，是两件不同的事情。实习更多是为了继续积累科研能力，也让老师能够更直接地了解你的工作方式和潜力。但毫无疑问，这些经历会为之后的选择提供很大的帮助。

大三寒假，经历了过年前几天的论文rebuttal，以及之后的焦虑等待。直到二月底，我很幸运地收到了论文被接收的消息。那一刻，我第一次真切地感受到，之前那些熬夜、失败和反复修改，并没有消失得毫无意义。它们也许不会立刻带来结果，但会在某个时刻，以另一种方式回应你。这也让我更加相信：科研有时候就像播种。你无法决定种子什么时候发芽，也不能保证每一次播种都会有收获，但如果从来没有播下种子，就永远不会等到结果。

相比大三上学期的高强度推进，大三下学期对我来说更像是一个短暂的间歇期。我开始重新进行学习和方向调研，也因为准备保研夏令营，耽误了一些原本计划中的事情。到现在，我已经拿到了不错的 offer，也仍然在等待其他老师的进一步消息。最终的结果还没有完全确定，但我越来越相信，无论最后去哪里，本科阶段的科研经历都会让我更有能力去面对未来的未知。至少在下一次遇到陌生的问题时，我知道该如何开始，也知道在暂时看不到结果的时候，怎样继续走下去。

## 回望：一条不循规蹈矩、风险与收获并存的保研之路

从我的经历可以看出，大学三年里，我把大量时间投入到了自己喜欢的事情和科研论文中。每个人最公平地拥有的东西，或许就是时间。当我把时间分配给比赛、科研和兴趣时，自然就没有办法把全部精力都放在课程学习上。

所以，我的课程成绩并不算突出，没有特别亮眼的排名，甚至有些课程只是压线通过，好在没有挂科，也算守住了底线。最后，我拿到了保研名额，而科研经历也让我有机会去选择一些更看重科研能力、而不只是课程成绩的学校和课题组。

对我来说，整个大学过程是幸运的。幸运地在大一时联系到了贾旭老师，让我第一次接触到科研和比赛；幸运地在大二遇到了学长，并且抓住了机会，改变了自己的大学轨迹；幸运地在大三熬过了最难的呢段时间，完成了第一篇由自己核心参与并最终被接收的论文，让我在未来升学时拥有了更多选择。

但所谓幸运，并不只是“刚好遇到了机会”。更重要的是，在机会出现时，你是否愿意相信自己，是否愿意主动伸手去抓住它，又是否能够在遇到困难之后继续坚持。大一主动联系老师、参加比赛，大二主动争取机会并坚持下来，大三经历一个又一个难熬的夜晚，这些事情最后共同塑造了今天的我。

我不敢说努力和选择一定会换来想要的结果，但它们至少会让你在机会出现时，更有能力把它接住；也会让你在结果不如预期时，不至于一无所获。

### 刚进入大学的小朋友

不要害怕试错。大一也许是大学里时间相对充裕、包袱相对少的一段时期。你可以好好休息，也可以参加社团、尝试比赛、接触科研，甚至只是花时间了解自己真正喜欢什么。

重要的不是每一次尝试都必须成功，而是你愿意走出去，并在尝试之后留下属于自己的判断。即使最后发现某条路并不适合你，那也不算浪费，因为你至少更加了解自己了。

### 已经大二的同学

如果你真的对科研感兴趣，想要尝试一下，那么可以主动联系校内或其他学校的老师、学长，努力争取学习和实践的机会。被拒绝并不可怕，一次拒绝也不代表你没有能力。很多时候，机会不会自动来到你面前，需要你先主动敲门。

大二可能是本科阶段接触科研、积累基础的一个重要时期。只要愿意尝试，也愿意耐下性子坚持，你或许会在这段经历里收获比预想中更多的东西。

### 正在考虑未来的大三同学

大三时，最重要的是逐渐想清楚自己想走什么方向，也要结合自己的实际情况做判断。

如果希望申请外校保研，且成绩和排名还不错，可以继续参加科研、竞赛，积极寻找科研实习，为之后的选择做好准备。如果处在保研边缘，首先要尽量确保自己能够拿到保研资格，再去投入更多时间做自己想做的事情。而对于排名相对靠后的同学，则需要认真思考自己未来是考研、考公，还是直接工作。这个阶段的每一个选择，都需要自己搜集信息、评估现实，并且对结果负责。

最后，我想说，每个人的道路都不可复制，因为每个人本身就是独一无二的个体。大学里有很多种选择，也有很多种过法。别人的经历只能作为参考，不能直接成为你的标准答案。找到一条自己愿意走下去的路，并且为自己的选择负责，或许就是最好的答案。
