# 慢慢来，可以一直在路上

## 楔子

其实，我的大学生活比较平淡和普通，没有什么大风大浪，但也确实是我感到十分幸运和珍贵的一段成长经历

想把这些来时路记录下来，希望能给学弟学妹们一些参考和帮助，也给自己一份回忆和纪念

入学的时候，我属于基础比较一般，没有什么特长，不属于能和大家打成一片的性子，对于自己的大学生活也没有什么规划，也没有想着后面要保研或去做什么

我的大学生活，就起始于一片懵懂，但是又充满着对未来和一切新事物的憧憬

而大学，真的是一个很神奇的地方。我遇到了非常好的师长、前辈和同学们，能与他们一同成长是我的荣幸

感谢所有遇见与陪伴

下面记录一些，感觉对我的成长而言比较有用的资料和信息，大家可以各取所需，祝愿大家都能收获幸福快乐的大学生活~

## 关于科研的各种尝试

在科研上，我在这 3 年期间，其实做过非常多的尝试。最开始是跟着平平老师做图像超分，后来跟着贾旭老师做图像生成，再后来跟着刘倩老师做五指灵巧手。因为我感觉我对模型调参实在没有什么天赋，一直想接触比较偏物理的方向，所以做着做着就做到具身这个方向了（虽然没想到具身怎么突然火起来了，本来想找个小众赛道慢慢走来着）

提起这段经历，我只是想说，关于做研究，如果一开始也不知道自己想做什么，其实也不代表后面就不能做研究了。慢慢地尝试，慢慢地积累经验，慢慢地找到自己愿意花上点心的方向，其实也可以一直在路上

## 关于保研的一些小事

保研这段经历对我来说可谓刻骨铭心。我的保研策略可能不太一样，我想的是这个课题组我可能想去，我就联系一下然后开始接触，还有就是我可能感兴趣的方向，想去尝试一下，我就会同意跟着这个老师实习一段时间，做一段项目。因为想看看大火的VLA和世界模型是什么，所以实习了3个月，因为想试试人形机器人的强化学习训练，所以又去实习了。。。整个保研期间我只发过 3 封邮件，实习的也不是最终去向，现在看起来好像有点游戏人生了QAQ。

邮件少的好处是每个课题组可以有时间充分接触，坏处就是尝试的次数少，实习的好处是可以以较低的成本尝试不同的方向，但坏处就是需要投入时间和精力，尝试的次数少。人生没有白走的路，有收获是有收获，不过就保研这件事而言，说不上是好是坏吧，主包BG是学习排名11/64，综合排名15/64，最后去向是中科大，不过是去做开山，大家谨慎，依情况参考。

没有一个坚定的评价指标也是我在保研期间遇到的最大的困难和痛苦（痛彻心扉）。我作为一个很普通的女孩子，走就业还是走科研，其实我到保研末期已经不坚定了。说实话到现在，我也依然迷茫，不过这是我的人生课题了，不做赘述。

只是想说，在踏上保研路前，可以有意识地去想一下自己的评价标准。因为可以用于做决策的影响因素很多，而最后需要在比较短的时间做一个决定。有一个坚定的评价标准后便坚定地相信自己的选择，这样也许会在保研路上少一些迷茫和痛苦，多一些坚定和自信。

然后我在不知道自己想要什么的时候，看到一个小红书博主的分享，也放在这里，给像我一样或许犹豫不决的同学们一个参考：

> 与其预测三年后什么方向最值钱，不如尽可能给三年后的自己保留更多的选择权

所以或许不会单纯按照导师、学校 title，或者某个组今年就业特别好来排序，更关注几个更实际的问题：

1. 导师是否真的愿意给你自由，这个组过去几届学生到底去了哪？
2. 这个环境里能不能接触到足够优秀的人？
3. 这个选择，你到底想收获什么？

选择没有对错，没有哪个 offer 是标准答案。二十岁出头的我们，在掌握有限信息的时候，选一条自己愿意去走三年，也给未来留下足够可能性的路，就已经很不容易。而我们不管选择如何，总可以在不确定里，把日子继续过下去。

最后，希望爱与勇气与你们的成长同行，祝学弟学妹们在成长的路上都能收获属于自己的小确幸，前程似锦，一路生花~
