# 阅读说明与免责声明

## 阅读说明

远方的朋友，你好，有缘相见！欢迎阅读《DUT 未来技术学院生存指南》。

这是一份由学生自发维护的、非官方的经验手册。本手册主要围绕四个问题展开：

第一，**为什么写这份指南，大学到底应该怎么过？** 
在第一章「精神内核」中，我们会讨论从高中到大学的转变、未来学院和普通学院的不同、保研率之外未来学院真正提供的东西，以及如何面对绩点、综测、奖学金、内卷、焦虑、时间分配和人际关系等问题。

第二，**AI 应该怎么学？** 
在第二章「AI 成长主线」中，我们会介绍基础工具、AI 学习路线，以及 CV、LLM、机器人与具身智能、AI for Science、AI Infra 等方向的基本认识和学习路径。

第三，**在未来学院体制下，课程、竞赛、科研、升学应该怎么做？** 
在第三章「未院特色路径」中，我们会整理课程学习经验、竞赛经验、科研入门方法、保研与出国流程、往届去向等内容。这里的重点不是告诉你唯一正确的道路，而是尽量减少信息差，让你更早知道有哪些选择、每种选择大致意味着什么。

第四，**不同学长学姐是怎么走过来的？** 
在第四章「学长学姐路线合集」中，我们会邀请不同方向、不同经历、不同结果的同学分享自己的成长路线。你可能会看到 CV、LLM、机器人、AI4Science 等方向的经验，也可能会看到迷茫、失败、绕路和重新选择。这些真实经历不一定能被复制，但可以帮助你理解：大学并不是只有一种走法。

阅读本指南时，请注意以下几点：

1. **不要把任何一篇文章当成标准答案。** 
   大学中的选择高度依赖个人背景、兴趣、性格、资源、时间和阶段。同一条建议，对一个人可能是捷径，对另一个人可能是弯路。
2. **区分事实、经验和观点。** 
   政策、培养方案、课程安排、保研规则等属于事实信息，应以学校和学院官方通知为准；课程评价、科研建议、竞赛经验、升学判断等更多是个人经验；关于大学、未来学院、AI 方向和人生规划的讨论，则不可避免地包含作者个人观点。
3. **按需阅读，不必从头到尾读完。** 
   如果你是刚入学的大一小朋友，可以优先阅读「精神内核」「AI 学习基础路线」和「课程学习篇」，也可在闲暇之余将此文档的各个部分逐一阅读；如果你已经进入大二、大三，可以重点阅读「AI 方向地图」「科研篇」「竞赛篇」和「升学与发展篇」。
4. **欢迎补充、修正和反驳。** 
   这份指南不是某一个人的作品，也不应停留在某一届学生的经验里。如果你发现内容过时、表述不准确、观点有偏差，或者你有自己的经历想分享，欢迎通过 Issue、Pull Request 或其他投稿方式参与共建。
