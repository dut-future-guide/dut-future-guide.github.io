# RoboMaster

## 写在前面

RM 无疑是做机器人/具身智能的人的梦中情赛。它是真正把机械、电控、视觉、算法、嵌入式、工程管理和现场对抗揉在一起，用一场又一场比赛直接检验队伍的稳定性和执行力。你做出来的东西不是放在 PPT 里讲给评委听，而是要真的上场、真的对抗、真的在灯光、碰撞、延迟、断线和各种突发状况里跑起来。

也正因为如此，RM 看起来会非常劝退。笔者当年 RM 招新时也是看赛题太难直接没报名，转头走向了机电班；现在回头看，这大概是我做过的无数曲折的选择之一。所以如果你对机器人有兴趣，不要因为一开始看不懂规则、不会软件、没接触过硬件就直接放弃。RM 的门槛确实高，但很多东西并不是“学完再进队”，而是在队伍里被项目推着一点点学会。

当然，RM 也不是一个轻松刷奖的选择。你需要认真想清楚自己愿不愿意把大量课余时间、寒暑假和情绪能量投入到一台台真实机器人上。如果你非常感兴趣并愿意投入，RM 可能就是最接近“真正机器人项目”的竞赛之一。

下面的正文是 RM 三年老兵的分享。由于催稿较急，内容还较少，但已经能帮助你建立对入队、备赛和参赛节奏的基本认识。后续也许会有更多队员愿意补充，也会继续更新这部分内容。

## 入队

每年的招新一般在开学的九十月份开始，具体最早的招新可能根据队里安排会不太一样，但是基本出了细则后都会有往届同专业的学长学姐在群里转发宣传。一般这个时候就可以陆陆续续进入招新群了，每年固定的一次招新会在百团大战的时间，rm基本会有一个单独的摊位进行一个招新宣传路演，这个时候可以和老队员交流了解一下比赛情况也可以近距离接触机器人。

进入招新群后只是第一步，由于报名人数较多，每年队里会进行一次筛选，但考核方式每年会有不同的变化，如23级为线下的培训及课题实践，24级为自由组队的校内赛，由于每年的管理层招新策略的改变，具体的入队考核方式也会有所变化，我们一般会分电控、机械、算法三个方向进行招生，大家可以根据自己的兴趣进行报名。

由于新加入的队员基本以大一新生为主，参加rm可能不需要太强的基础，但是需要较强的自驱力和自学能力。

23级机械组学长的入队经验：我们当年队伍的宣传力度较大，在开学前班导就已经在群里转发了战队的相关信息，我也较早地进行了报名。在方向选择上大家可以根据自己的兴趣喜欢来，但是建议在后续学院分流时可以选择和自己在队里工作对应的专业，我本人在队里干的机械的工作但是本身走的是人工智能，对后续的保研会产生一些影响，在项目上就会出现不太匹配的情况。

在报名后会有入队考核，我这一届机械组需要先自学solidworks的使用，根据图纸来进行一个简单的建模。经过初步筛选后，需要选择一个正式的课题，之后会进行一个持续两个月的培训，每周有固定的线下统一上课时间，学长会教学建模软件的使用技巧以及机械设计的注意点，也会教学实验室各个加工器械的使用。

这段时间的出勤率、每天到实验室打卡的时长等都会对后续入队产生一些影响，在经过两个月的学习后基本能初步确定是否能够留在队伍，然后根据个人意向，分派到对应的兵种，然后开始加入紧张的备赛过程中。

以上仅为23级经验，26级由于规则变化兵种合并可能会发生很多变化，以及每年的招新节奏也会不同。重要的是有自学多问的能力，以及是否愿意花费时间大量投入，rm赛场较长贯穿整个下班学期一直到八月初，需要花费大量的时间精力来备赛，不可避免地会影响到学业成绩，大家也要做好准备做好平衡学业和竞赛。但是在竞赛加分上，如果能够打满两年并且再在其他较简单保研加分赛事上刷一点分，每年的科创奖学金及保研加分还是很容易拿满的。就是由于队里人数较多并且学院对多人参赛有加分百分比乘法，在大一第一年可能加不到多少分。

## 备赛

在进入队伍后，就要开始进行紧张的备赛。在加入rm队伍前，就必须做好牺牲大量的假期和平常课余时间用于备赛的准备。rm的赛程较长，每年至少经历三阶段的比赛，我入队那年比较特殊，我们经历了四阶段的赛程，短短一周的比赛背后是赛前几个月的努力，虽然会很辛苦但也会收获良多。在寒假期间往往为放假前留校两周、开学前提前一周到校的节奏，因为往往第一阶段的赛程联赛往往在开学的第一个月即三月份就展开，备赛时间非常紧张，每年为了适应新规则往往需要设计新的机器人构型，寒假期间会花费很多时间来造新车，但是在联盟赛能够发挥稳定的还是以老车为主，而老车的维护工作往往会分配到很多新队员身上。在这个阶段，新队员可能会既需要跟随老队员参与新车的制作，又需要负责一部分老车的维护工作，可能会轻视对老车的维护，但是如果你希望在联盟赛就有主力成员的身份，就要做好老车的维护，这是决定队伍能否在联盟赛取得一个好成绩极为重要的因素。

## 参赛

联盟赛相当于一整年赛事的预热，以3v3的对抗为主，难度相对较低，也会有比较多实力较弱的学校参赛。联盟赛的对抗登场车辆为一台步兵、一台英雄、一台哨兵，但是27年的规则有变化，英雄兵种不存在了，可能联盟赛也会发生改变。如果你在一开始加入的是飞镖、无人机等兵种，这个阶段不需要参与，就继续留校准备超级对抗赛就行，那里才是你们发挥的舞台。

在联盟赛的阶段，上场的名额较少，每个兵种几乎只能登场一人，老队员也都只有几个登场名额，新队员一般难以获得上场的机会，但是也不要灰心，后续的超级对抗赛中会有很多的机会。台下的工作一样重要，这个阶段更重要的是了解这个赛事，了解整个参赛流程，跟随老队员参与一次次的检录并亲自上手参与，了解整个裁判系统和检录的技巧，因为后续赛程检录都是很重要的一环。因为理论上部分兵种只允许一个人检录，联盟赛管的不太严，可以跟着学习，到后续赛程由于机器人数量太多，需要新队员自己单独完成检录流程。

联盟赛往往是大部分新队员第一次真正了解rm是什么的阶段，第一次熬夜紧张维修车辆，第一次群策群力解决各类突发状况，第一次在赛场边为队伍加油，可能会有遗憾但更多的是收获。联盟赛的成绩对后续并没有太大的影响，但也是比较好拿加分的一个阶段，所以赛前的备赛阶段要尽量用自己的良好表现争取到一个正式队员的名额。

联盟赛结束后会有长达两个月的超级对抗赛区域赛的备赛时间，这个时候千万不能因联盟赛的顺利而放松警惕，25年就出现了类似的情况。每年的区域赛我们学校的发挥都不是特别好，当然这也和我们学校的考试时间有关，每年五月都会有很多课程结课以及一些科目的期中考，不可避免地影响到备赛进度，这个时候也要做好学业和竞赛平衡。

分区赛我们学校一般会选择五月底也就是最晚开始的赛区，但是备赛时间依然很紧张，这个阶段可能是一整年最累的一个备赛阶段，既需要顾及各类学业考试，又带着一些可能还未上过场的新车进行正式的比赛，这个过程中会发生各类突发情况，而且不同于联盟赛时人员比较充足，分区赛时往往各个兵种都自顾不暇，更加考验临场应变能力和赛前准备的充分程度。这个过程可能会有各种矛盾发生，这个时候就更考验到队员的团队意识，rm赛场是一个非常需要责任心的比赛，在完成自己的工作后如果富有余力，也可以尽量问问其他兵种是否需要帮助，比赛的结果需要的是整个队伍的努力，任何一个兵种的故障都会对比赛有巨大的影响，稳定性决定了整个队伍的下限。

分区赛的成绩决定了能否拿到春茧八月全国赛门票，每个赛区的名额数量会根据参赛队伍的实力情况进行调整，排名靠前的能够拿到直通国赛的名额，稍靠后的也有机会参与复活赛，但这需要在国赛开始前经历艰难的复活赛拿到仅有的四个名额才能进入国赛。这几年我们学校的成绩基本保持上升趋势，从24年的遗憾止步复活赛，到25年从复活赛一路杀出重围，创造了全国六强的队史，以及26年，稳定住了12强的好成绩，0bug战队正逐渐向成为一个强队在稳步迈进。

国赛的赛程和规则基本与分区赛不会有太大的区别，但在经过分区赛的洗礼以及一个月的练习及全力备赛，车辆往往能有更好的稳定性，会相较于分区赛较为轻松一些，但是在全国赛也要面对更为强大的对手。更大的场馆、更激烈的对抗、更广泛的宣传度，robomaster全国赛的赛场绝对能够成为你大学阶段一段重要的回忆。
