## 阅读提醒

!!! warning "非官方说明"
    本指南为学生自发维护的非官方文档，不代表学院、学校或任何组织的官方立场。政策、培养方案、通知等内容请以官方发布为准。

!!! tip "把它当作路线图，而不是标准答案"
    每个人的基础、资源、兴趣和目标都不同。更好的读法不是照抄某条路径，而是把这里的经验拆成问题，再带着这些问题去找老师、学长学姐、课程、项目和真实反馈。
